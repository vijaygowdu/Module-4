## EX.NO:4(D)	Exception Handling in Python: Avoiding Index Errors
## AIM:
To Place msg="You're out of list range" to avoid Index Error.

## ALGORITHM:

Step1: Input a list 

Step2: try print(list1(5))

Step3: except print that you are out of range

Step4: Execute the program.
## PROGRAM:
```
list1=[5, 10, 20]
try:
   print(list1[5])
except:
   print("You're out of list range")

```
